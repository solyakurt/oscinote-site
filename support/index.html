Support

System requirements

Windows: Windows 10 or 11, 64-bit; Microsoft WebView2 is installed automatically if it is missing.

Microphone permission

  • Windows: Settings → Privacy & security → Microphone → let desktop apps access your microphone.

Audio interfaces

Any input your system offers can be chosen in Settings → Audio. Oscinote records one mono track; set the input gain so the level meter stays out of the red.

How accuracy is measured

Every build of Oscinote is tested with tones whose pitch is known exactly: pure and plucked tones, clean and with noise 20 dB below the signal, at 44.1 and 48 kHz. The tuner reads them within ±1 ¢ from 28 to 1,400 Hz and within ±2 ¢ up to 2,100 Hz. The analysis puts note medians within 3 ¢ with no wrong notes, and slowed-down playback keeps the pitch within ±2 ¢.

Real instruments have attacks, breath and string noise and overtones that are not perfectly in tune, so their readings move more than a test tone’s.
