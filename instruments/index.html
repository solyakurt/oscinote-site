Supported instruments

String profiles get tuning presets, automatic string detection and a string lock. Everything else gets a chromatic tuner with an optional target note. All analysis is one note at a time.

Not supported: chord recognition and polyphonic transcription. The two strings of a 12-string or mandolin course cannot be told apart when they sound together. Accuracy figures come from synthetic test signals; real instruments read less steadily.
